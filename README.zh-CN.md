# KiriTori

[English](README.md) | [日本語](README.ja.md) | 简体中文

KiriTori 是一款基于 Chrome Manifest V3 的本地截图扩展。截图与图像处理均在浏览器内完成，不会将页面内容上传至外部服务。

界面跟随 Chrome 显示语言，支持英语、日语、简体中文和繁体中文；其他语言默认使用英语。更改 Chrome 显示语言后，如有需要请重启 Chrome。

## 安装

1. 打开 `chrome://extensions`，启用「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本扩展所在文件夹。
3. 从 Chrome 工具栏打开 KiriTori。

## 截图与输出

可拍摄当前可见区域、手动选择的区域、纵向滚动的整个页面，或页面内纵向滚动的表格等区域。支持 PNG、JPEG 和 PDF；文件可保存到 Downloads 下的子文件夹。也可将图片以 PNG 格式复制到剪贴板，PDF 仅支持保存为文件。

选择页面内的滚动区域后，KiriTori 会从上到下拍摄并拼接当前可见宽度的内容，并在结束或取消后恢复原有滚动位置。区域必须完整显示在视口中。区域内的固定表头仅保留在第一屏，以避免重复；水平滚动隐藏的内容和其他框架内的滚动区域不包含在内。

可设置立即拍摄、3 秒或 5 秒后拍摄。等待时，页面和扩展图标会显示倒计时；可以在此期间打开菜单或工具提示。区域选择和隐藏元素选择会在等待结束后开始。右键菜单、快捷键和网站设置也会使用该等待时间。

## 逐页截图

选择「逐页拍摄」，再点击页面上的「下一页」按钮。KiriTori 会依次拍摄各页的可见区域：PNG、JPEG 保存为编号图片，PDF 保存为一个多页文件。可设置最多拍摄 1～50 页以及翻页后的等待时间，并可在进度界面取消。

如果按钮被禁用或隐藏、页面重复、无法确认按钮或页面没有发生变化，拍摄会停止，并保留已拍摄的页面。加载较慢时可延长等待时间。拍摄期间请保持标签页处于激活状态，且不要改变窗口尺寸。跨来源链接、打开新标签页的链接和部分网站的特殊翻页方式不受支持；总图片尺寸限制同样适用。

启用预览后，可在保存前逐张查看或纵向排列查看所有页面。此模式的预览不支持编辑图片，也不支持复制到剪贴板或隐藏广告。

## 文件名与长页面

文件名可选择页面名、日期和网站名的排列顺序；日期使用本地时间，网站名使用域名。保存位置为 Downloads 下的相对路径，例如 `Screenshots/Research`。可在 Chrome 设置中更改 Downloads 的实际位置。

拍摄整个页面或滚动区域时，可按屏幕高度拆分保存：PNG、JPEG 输出编号文件，PDF 输出多页文件。复制时仍使用完整图片。滚动截图的上限可设置为 1～200 屏，默认 80 屏；达到上限时输出已拍摄的部分。拆分输出仍受总计 8000 万像素、任一边不超过 32000 像素的限制，文字或图片也可能恰好被拆分位置截断。

滚动后的额外等待时间可选择快速（200 毫秒）、标准（600 毫秒）、缓慢（1500 毫秒）或自定义（0～10000 毫秒）。等待滚动稳定及 Chrome 的截图频率限制可能使实际间隔更长。

## 隐藏广告和其他元素

「隐藏广告后拍摄」默认关闭。启用后，扩展会在拍摄期间暂时隐藏符合常见广告标签、ID、类名或已知广告网络 iframe 特征的元素，拍摄后恢复。它可能遗漏广告，也可能误隐藏其他元素。

还可在拍摄前手动点击选择要隐藏的元素。支持选择多个元素、撤销上一次选择、使用上下方向键切换父子元素，以及完成或取消。拍摄结束或取消后元素会恢复。隐藏元素可能改变页面布局；无法单独选择 iframe 内元素时，可选择整个 iframe。

## 预览与编辑

普通截图默认在输出前打开预览编辑页，可裁剪并添加箭头、文字、矩形、椭圆、直线、编号标记、马赛克、不透明填充和半透明高亮。关闭预览后会直接输出。

文字可直接点击图片输入；在「选择和调整」中可移动、修改，并拖动白色手柄调整大小、拖动蓝色手柄旋转。箭头、直线和图形也可调整或删除。可从基本色或调色板选择颜色，最多在本机保存 12 个自定义颜色。编号标记按顺序添加，下一编号为现有最大编号加一。

支持撤销、重做和重置；Mac 可使用 `⌘Z` / `⌘⇧Z`，Windows 可使用 `Ctrl+Z` / `Ctrl+Shift+Z` 或 `Ctrl+Y`。马赛克颗粒大小可设置为 2～160 像素，数值越小颗粒越细。马赛克后的文字仍可能被辨认；分享前请检查。填充为不透明矩形，高亮为半透明，不能用于隐藏内容。

预览中的「重新拍摄」使用原标签页和相同设置；如需选择区域或手动隐藏元素，须重新选择。原标签页已关闭或已切换至其他页面时无法重新拍摄，恢复的草稿也不能重新拍摄。

## 本地编辑草稿

可设置不保存草稿，或保存 1、7、30 天，默认 7 天。草稿包含原始图片和编辑内容，保存在本机；可从弹出窗口恢复、逐个删除或全部删除。输出后草稿仍保留至过期或被删除，过期草稿在下次打开 KiriTori 时清理。原图包含填充遮盖前的内容，不再需要时请删除草稿。保存期限的变更适用于之后打开的编辑页。

## 网站设置、快捷键与进度

启用「保存此网站的设置」后，截图范围、格式、保存位置等设置按主机名保存在本机，重新打开弹出窗口和使用快捷键时自动应用。右键菜单只覆盖截图范围，其余使用网站设置。子域名分别保存；关闭该选项可删除当前网站设置并返回共用设置。

网页右键菜单提供截图命令。默认快捷键为 Windows 的 `Ctrl+Shift+8` 或 Mac 的 `Command+Shift+8`，可在 `chrome://extensions/shortcuts` 中修改。长页面和逐页截图可查看进度并取消；输出开始后不能取消。

弹出窗口在本机保存最近最多 10 条失败记录，包括时间、范围、阶段和可用的原因及处理建议；不记录截图、页面 URL、标题或原始错误信息，可手动清除。如果输出中途失败，部分文件或剪贴板内容可能已经生成。

## 限制与权限

Chrome 内部页面、Chrome 网上应用店及其他扩展无法访问的页面无法拍摄。全页和滚动区域截图仅沿垂直方向拼接；固定或粘性元素会在全页拍摄期间暂时隐藏，以避免重复。返回顶部按钮和广告的识别基于常见特征，不保证覆盖所有网站。

- `activeTab`：访问用户调用扩展的标签页。
- `scripting`：显示选择界面并控制页面滚动。
- `downloads`：将文件保存到 Downloads 下。
- `offscreen`：拼接、转换图片并写入剪贴板。
- `clipboardWrite`：在用户选择时复制图片。
- `contextMenus`：提供网页右键截图命令。
- `storage`：在本机保存并共享截图设置。
